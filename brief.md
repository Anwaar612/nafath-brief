## Overview

Software, AI, mobile technology, networking, cybersecurity, and data work together to support modern digital services and research. Software provides the programs that run on computers and mobile devices, while AI adds capabilities such as learning from information and generating predictions or responses. Mobile devices let people use these services anywhere and can collect data through apps and surveys. Networks connect devices and transmit that data to other systems, including cloud-based software. Cybersecurity helps protect devices, communications, and information from unauthorized access or misuse. Data is the foundation for many of these activities: it can be gathered through mobile tools, transferred across networks, stored and processed by software, and analyzed by AI. Together, these fields enable services such as mobile research apps and chatbots, while also making privacy, accuracy, reliability, and security important considerations.

## Software

Software is a set of programs and related instructions that tell a computer how to perform tasks. It includes operating systems, which manage hardware and support applications, and application software, which serves specific user needs. Software is created through design, programming, testing, release, and maintenance. It may run locally or be delivered online as software as a service (SaaS). Its development connects to other fields because software can use AI, run on mobile devices, communicate over networks, handle data, and require cybersecurity protections.
